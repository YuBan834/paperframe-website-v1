# PaperFrame Personal Website V1

这是开发者纸帧（PaperFrame）的第一版个人网站归档。

它保留了最初的 Windows 桌面式布局、昼夜切换、粒子连线、个人信息窗口与联系窗口，作为后来个人网站 V2 的起点。

## 在线体验

发布 GitHub Pages 后，从仓库首页提供的 Pages 地址访问。

## 说明

- 本版本为纯静态归档，可直接部署到 GitHub Pages。
- 原留言接口依赖本地 Node.js 服务，公开归档中已停用，避免访问者误把信息发送到无效地址。
- 当前维护中的版本是 Personal Website V2。

## 本地查看

直接打开 `index.html`，或使用任意静态文件服务器访问本目录。
